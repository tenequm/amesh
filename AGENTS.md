# amesh

amesh is a public open-source tool. Code, tests, docs, examples, commit messages and the contract copy hold no personal paths, host or domain names, user or agent names, emails, machine ids, chat ids or other identifiers from any real deployment. Use neutral values: `/Users/me/...` or `/home/me/...`, `~/work/...`, `hub.example.com`, machine names such as `laptop`, `server` or `mac`, sessions such as `review@webapp:mac`, an agent such as `atlas`. `just leaks` (also run by the Git hooks and CI) scans with [.betterleaks.toml](.betterleaks.toml); add a pattern there when a new kind of private value turns up, never the value itself.

Use `just fmt` to format and `just check` to run the formatter check, lint and race tests. Keep stdout reserved for the subcommand's output.

[api/openapi.yaml](api/openapi.yaml) is generated by the contract's generator, which lives with the hub's design docs outside this repository. Change the contract there first, regenerate it, and copy the result byte for byte; never edit the copy by hand. Run `go generate ./internal/contract` after a schema change.

The mode backends implement the interfaces in `mcpserver`. Each has one constructor in the daemon wiring. Keep lane communication local. Take connection identity from `peercred.Read`, and re-resolve the session on each call. A daemon without a hub URL halts its hub client with `hub.ErrNoHub` and keeps lane mode working.

Use `testing/synctest` for timeouts and backoff, short Unix socket paths for fake inboxes, and a recording `httptest` hub for HTTP. A lost response can be simulated with `panic(http.ErrAbortHandler)`.
